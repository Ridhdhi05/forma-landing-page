# 📐 Forma — Product Landing Page

## 📌 Project Overview
**Forma** is a design-focused learning platform and landing page built around interactive, project-based education. It empowers aspiring designers to build real skills through hands-on practice ("Good design starts with doing")[cite: 3].

---

## 🎯 Target Audience & Use Case
* **Primary Users:** Students, junior designers, and self-taught creatives aiming to transition from collecting inspiration to building production-ready design systems[cite: 3].
* **User Pain Points Addressed:** 
  * Overwhelm from endless browser tabs and purely theoretical video tutorials[cite: 3].
  * Lack of practical, portfolio-ready projects[cite: 3].
  * Need for a structured, step-by-step pathway to master tools like Figma[cite: 1, 3].

---

## 🎨 Design System & Rationale
* **Typography:** Modern, clean sans-serif typography with high visual hierarchy between bold section headlines ("Good design starts with doing", "Small projects. Real skills.") and body copy[cite: 3].
* **Color Palette:** 
  * **Background:** Soft warm light-gray/off-white (`#F5F4EE`) to keep visual strain low during study sessions[cite: 3].
  * **Primary Accent:** Vibrant electric purple (`#6338F6`) for high-visibility call-to-action (CTA) buttons, pricing badges, and interactive elements[cite: 3].
  * **Secondary Tones:** Lavender, pastel green, and peach card backgrounds to visually differentiate course modules[cite: 3].
* **Layout & Components:**
  * Built using **Figma Auto Layout** to maintain strict spacing, grid alignment, and responsive container wrapping across headers, feature cards, course blocks, pricing tiers, and footers[cite: 1, 3].
  * Reusable UI components used for navigation buttons, course cards, testimonial banners, and pricing structures[cite: 1, 3].
